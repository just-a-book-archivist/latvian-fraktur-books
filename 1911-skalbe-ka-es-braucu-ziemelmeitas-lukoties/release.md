Kārļa Skalbes pasaka „Kā es braucu Ziemeļmeitas lūkoties“ (1911), salikts izdevums: teksts
vecajā rakstībā, salīdzināts ar skenējumu vārdu pa vārdam un rindu pa rindai.

The literary fairy tale by Kārlis Skalbe (1879–1945), *Kà es brauzu Seemełmeitas luhkotees*
(Pēterburga: A. Gulbis, [1911]), typeset from the transcription in
[`1911-skalbe-ka-es-braucu-ziemelmeitas-lukoties/`](https://github.com/just-a-book-archivist/latvian-fraktur-books/tree/main/1911-skalbe-ka-es-braucu-ziemelmeitas-lukoties).
Latvian in the orthography before the reform of the 1920s, nothing modernised: the long ſ, the
stroked letters (ꞩ ꞥ ł ꞧ ꞣ ꞡ) and the accents stay as printed.

The text went through two passes against the scans: every word (first proofreading, 8 October
2026) and every printed line, for punctuation, hyphens and paragraphs (second proofreading,
21 October 2026).

## Files

| File | What it is |
|---|---|
| `…-lesefassung-antiqua.pdf` | **Reading version, roman type.** The text in paragraphs, line-end hyphens resolved. Best for reading, copying and searching. |
| `…-lesefassung-fraktur.pdf` | **Reading version, Fraktur.** The same in a Fraktur typeface. It has no stroked letters, so the stroke is drawn over the base letter; the text layer holds the base letter (`ſ` for `ꞩ`). |
| `…-diplomatisch-antiqua.pdf` | **Diplomatic version, roman type.** Every printed page and line as in the print, hyphens as printed, the cover first. For comparing with the scans. |
| `…-diplomatisch-fraktur.pdf` | **Diplomatic version, Fraktur.** The same in Fraktur, strokes drawn as above. |
| `…-lesetext.txt` | The reading version as plain text (UTF-8), one paragraph per line. |
| `…-diplomatisch.txt` | The diplomatic version as plain text (UTF-8), page by page. |
